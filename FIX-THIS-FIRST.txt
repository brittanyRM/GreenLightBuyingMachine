FIXING THE BUILD
================

WHAT WENT WRONG
  The last upload landed one folder too deep. Instead of merging into
  the repo, the whole zip went inside app/. You ended up with:

      app/app/          app/components/
      app/lib/          app/next.config.js   app/READ-ME.txt

  Those files import things like '../../../lib/queries', which only
  resolves from their real location. One level deeper it points at
  nothing, so the build failed with "Module not found". None of the
  eight changes took effect either — they never reached app/ and
  components/ proper.

STEP 1 — DELETE THESE IN GITHUB (uploading will not remove them)

  Folders — delete the files inside and the folder disappears:
      app/app/
      app/components/
      app/lib/
      app/proforma-club/
      components/app/
      components/components/

  Files:
      app/next.config.js        (the real one is at the repo ROOT)
      app/READ-ME.txt
      READ-ME.txt
      READ-ME-FIRST.txt
      UPLOAD-THESE.txt
      CHANGES-THIS-UPDATE.md
      ClubProForma.jsx          (root — real one is components/)
      ContactDetail.jsx         (root — real one is components/)
      PipelineBoard.jsx         (root — real one is components/)
      004_crm.sql               (root — real one is supabase/migrations/)
      crm.js                    (root — real one is lib/)
      chk.mjs                   (root — scratch file)
      components/UPLOAD-THESE.txt

STEP 2 — UPLOAD
  Extract this zip. Open the extracted folder so you can SEE app,
  components, lib, public, package.json etc.

  Drag THOSE ITEMS — not the folder that contains them. Dragging the
  outer folder is exactly what caused this.

  In GitHub: Add file → Upload files → drop them in → Commit.

VERIFIED
  This exact tree runs `next build` successfully. 40 routes compiled,
  no errors.
