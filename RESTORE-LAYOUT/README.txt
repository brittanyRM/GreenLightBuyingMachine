ONE FILE — components/ClubProForma.jsx

WHAT THIS DOES
  Puts the buyer sheet layout back exactly as it was. I had moved
  "What's included", the scenario basis and the photo gallery below
  the numbers, and pulled the room revenue stack out of the Summary
  tile. All three are reversed.

  The only thing still different from your original: the pro forma
  (income, net performance, capital, down payment options) always
  renders instead of being a tile that can be switched off. That was
  the change you asked for.

HOW TO APPLY — in the Codespace terminal, one line at a time:

  1.  Drag this README's folder into the file explorer, OR just
      replace the file directly:
      open components/ClubProForma.jsx in the editor, select all,
      paste in the new contents, save.

  2.  git add -A

  3.  git commit -m "Restore buyer sheet layout"

  4.  git push
